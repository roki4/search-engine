# How to start frontend and backend?
```
git clone https://github.com/roki4/search-engine.git
cd search-engine
npm i
cd ./src/client/
npm i
cd ../server/
npm i
cd ../../
npm run start
```

# How to start backend?
```
cd ./src/server/
npm run dev
```

# How to start frontend?
```
cd ./src/client/
npm run serve
```
